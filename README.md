# AB Fashion Shopify theme

AB Fashion is an Online Store 2.0 theme. Products, vendors, product types,
tags, variants, pricing, inventory, collections, filters, and orders remain
managed by Shopify Admin; the theme only renders the native Shopify objects and
routes. Configure optional product ratings in Shopify Admin under
`custom.rating` and `custom.review_count` metafields. Ratings are omitted when
those metafields (or a supported reviews app metafield) are not present.

The collection template uses Shopify's native storefront filtering,
`sort_by`, pagination, and collection routes. Single-variant products use the
native `/cart/add` form for Quick add; products with options link to their
native product page for variant selection.
